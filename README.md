# homebrew-tap

This is a Homebrew tap for @icco's projects.

## Installation

```bash
brew tap icco/tap
```

## Available Casks

- **art** - Personal scheduling agent — TUI for the art server
  ```bash
  brew install art
  ```

  See [github.com/icco/art](https://github.com/icco/art) for more information.

- **bugsim** - An attempt at a flight sim for programmers
  ```bash
  brew install bugsim
  ```

  See [github.com/icco/bugsim](https://github.com/icco/bugsim) for more information.

- **etu** - A personal command line journal
  ```bash
  brew install etu
  ```

  See [github.com/icco/etu](https://github.com/icco/etu) for more information.

- **gitstatus** - Git repository status as one line, for a shell prompt
  ```bash
  brew install gitstatus
  ```

  See [github.com/icco/gitstatus](https://github.com/icco/gitstatus) for more information.

- **gotak** - A CLI client for the Tak board-game server
  ```bash
  brew install gotak
  ```

  See [github.com/icco/gotak](https://github.com/icco/gotak) for more information.
